About this guide

이 교안은 교육 후 참여자가 혼자서도 따라할 수 있도록 작성되었습니다.

시연할 전체 과정을 단계별로 정리했으며, 링크와 설명을 따라가면 코딩 경험 없이도 나만의 웹사이트를 만들고 배포할 수 있습니다.

1단계

바이브코딩 맛보기

⏱ 15분

AI에게 요청하면 즉시 코드가 만들어진다는 것을 체감합니다. 지금부터 배울 과정은 여기서 한 걸음 더 나아가 '내 것으로 배포'까지 하는 것입니다.

왜 이 단계가 필요한가?
"코딩을 몰라도 된다"는 말이 실제로 가능한지 눈으로 확인하는 단계입니다. 두려움을 없애고, 이후 단계에서 무엇을 향해 나아가는지 맥락을 잡는 시간입니다.

  • Replit으로 간단한 웹앱을 직접 생성
  • Google AI 스튜디오에 요청해 결과물이 생성되는 모습 확인
  • "AI에게 요청하면 코드가 나온다"는 개념을 체감
  • Replit과 AI 스튜디오는 빠른 프로토타이핑에 최적 — 이후 단계에서 배우는 방식은 실제 배포와 운영에 더 가까운 흐름
Replit 바로가기 ↗ Google AI Studio ↗

💡 참여자 가이드

Replit과 AI 스튜디오는 빠르게 체험하기 좋은 도구입니다. 다만 크레딧 소진 방식이라 사용할수록 비용이 발생하고, 결과물을 내 것으로 보관하거나 지속 운영하기도 번거롭습니다. 이후 단계에서 배우는 GitHub + 안티그래비티 + Vercel 조합은 비용 부담이 적고 실제 서비스 운영에 더 가까운 방식입니다.

2단계

GitHub 가입 및 레포 생성

⏱ 10분

내 코드를 저장하고 관리하는 공간을 만듭니다. 이후 모든 배포와 코딩 툴이 이 GitHub 계정과 연결됩니다.

왜 이 단계가 필요한가?
GitHub은 코드의 저장소입니다. AI가 만들어준 코드를 저장하고, Vercel 같은 배포 도구가 이 저장소에서 코드를 읽어 자동으로 웹사이트를 배포합니다. 모든 흐름의 중심입니다.

  • GitHub은 코드 파일을 저장·버전 관리하는 플랫폼
  • github.com에서 이메일로 무료 회원가입
  • 상단 "+" 버튼 → "New repository" 클릭
  • 레포지터리 이름: 영문 소문자 + 하이픈(-) 사용 (예: my-portfolio)
  • 옵션 설정: Public 선택 + Add a README file 체크
  • "Create repository" 버튼 클릭으로 완성
GitHub 바로가기 ↗

💡 참여자 가이드

레포지터리 이름은 영문 소문자와 하이픈(-)만 사용하세요. 예: my-portfolio, vibe-web. 생성 시 "Public"과 "Add a README file" 옵션을 반드시 체크하세요. 이후 Vercel 연결 시 레포가 Public이어야 무료로 배포할 수 있습니다.

3단계

안티그래비티에 GitHub 연결

⏱ 10분

AI 코딩 툴이 내 GitHub 레포에 직접 코드를 올릴 수 있도록 연결합니다.

왜 이 단계가 필요한가?
안티그래비티는 Google AI Pro 기반의 바이브코딩 툴입니다. 이 툴이 내 GitHub 저장소에 접근할 수 있어야, AI가 생성한 코드가 자동으로 저장소에 반영되고 이후 Vercel이 그 코드를 배포할 수 있습니다.

  • antigravity.so 접속 → Google 계정으로 로그인
  • 로그인 후 "GitHub 연결" 또는 연동 메뉴 진입
  • GitHub 권한 허용 화면에서 "All repositories" 또는 특정 레포 선택 가능
  • 2단계에서 만든 레포를 연결
  • 워크스페이스 생성 확인 — 오른쪽 상단에 연결된 레포 이름이 표시되면 완료
안티그래비티 바로가기 ↗

💡 참여자 가이드

안티그래비티 연결 순서: Google 계정 로그인 → GitHub 권한 허용. GitHub 연결 시 "All repositories" 대신 방금 만든 레포만 선택해도 됩니다. 워크스페이스 생성 후 오른쪽 상단에 연결된 레포 이름이 표시되면 정상적으로 연결된 상태입니다.

4단계

Vercel 가입 및 GitHub 연결

⏱ 10분

GitHub에 올라온 코드를 자동으로 인터넷에 공개하는 배포 자동화를 설정합니다.

왜 이 단계가 필요한가?
GitHub 저장소를 연결해두면, 이후 코드가 변경될 때마다 자동으로 최신 버전의 웹사이트를 배포합니다. 별도 서버 설정이나 배포 버튼을 누를 필요가 없습니다.

  • vercel.com 접속 → "Start Deploying" 또는 "Sign Up" 클릭
  • GitHub 계정으로 바로 가입 (별도 이메일 불필요)
  • "Import Git Repository" → 2단계에서 만든 레포 선택
  • 설정은 기본값 유지 → "Deploy" 버튼 클릭
  • 자동 배포 원리: 코드 변경 → GitHub 푸시 → Vercel 감지 → 자동 배포
Vercel 바로가기 ↗

💡 참여자 가이드

Vercel은 GitHub 계정으로 바로 가입할 수 있습니다. 프로젝트 연결 시 "Import Git Repository"에서 방금 만든 레포를 선택하면 됩니다. 이후에는 안티그래비티에서 코드를 수정할 때마다 Vercel이 자동으로 감지해 새 버전을 배포합니다.

5단계

프롬프트 만들기

⏱ 15분

AI에게 잘 전달하는 것이 결과물 품질을 결정합니다. Gemini를 활용해 구조화된 프롬프트 작성법을 익힙니다.

왜 이 단계가 필요한가?
"웹사이트 만들어줘"와 "개인 포트폴리오 사이트, 다크모드, 자기소개·프로젝트·연락처 섹션 포함, 심플한 디자인"은 전혀 다른 결과를 만듭니다. 구체적인 프롬프트가 원하는 결과물의 첫 번째 조건입니다.

  • 좋은 프롬프트의 5가지 요소: 목적 / 대상 / 기능 / 디자인 스타일 / 기술 스펙
  • Gemini에 프롬프트 초안 작성을 요청하는 방식 시연
  • 예시 요청: "개인 포트폴리오 웹사이트, 심플한 디자인, 다크모드, 자기소개/프로젝트/연락처 섹션 포함"
  • 작성된 프롬프트 검토 — 빠진 요소 체크 및 보완 방법 설명
  • 원하는 색상·레이아웃·언어까지 구체적으로 포함하면 더 좋은 결과
Gemini 바로가기 ↗

💡 참여자 가이드

Gemini에 이렇게 요청해보세요 →
"바이브코딩 툴에 넣을 프롬프트를 작성해줘. 만들고 싶은 것: [내용]. 포함할 기능: [기능]. 디자인 스타일: [스타일]."

프롬프트는 자세할 수록 좋습니다. 원하는 색상, 레이아웃, 언어(한국어 등)까지 구체적으로 적으면 AI가 더 정확하게 만들어줍니다.

모델 선택 팁: 입력창에서 모델을 직접 선택할 수 있습니다. Flash는 빠른 응답으로 가볍게 쓰기 좋고, 사고 모델(Thinking)은 복잡한 추론이 필요할 때 유용하며, Pro는 가장 강력한 성능이 필요한 작업에 활용해 보세요.

6단계

안티그래비티로 코딩 요청

⏱ 15분

준비한 프롬프트로 실제 코드를 생성하고, GitHub에 반영되는 과정을 실시간으로 확인합니다.

왜 이 단계가 필요한가?
이 단계가 바이브코딩의 핵심입니다. AI에게 의도를 전달하고, 결과를 보고, 다시 요청해 완성도를 높여가는 반복 과정이 실제 작업 방식이 됩니다.

  • 안티그래비티 워크스페이스에 5단계에서 만든 프롬프트 입력
  • AI가 코드를 생성하는 과정 실시간 관찰
  • GitHub 레포에 코드가 올라가는 것 직접 확인
  • 결과물 미리보기로 첫 번째 버전 확인
  • 수정 요청 방법 시연 — 추가 프롬프트로 반복 개선
안티그래비티 바로가기 ↗

💡 참여자 가이드

첫 결과물이 마음에 들지 않아도 괜찮습니다. "버튼 색을 검정으로 바꿔줘", "상단에 메뉴를 추가해줘"처럼 추가 요청을 반복하면서 완성도를 높여가는 게 바이브코딩의 핵심 방식입니다. 한 번에 완벽할 필요 없습니다.

7단계

Vercel로 배포

⏱ 15분

GitHub에 올라간 코드를 눈으로 확인하고 실제로 배포하는 마지막 단계입니다.

왜 이 단계가 필요한가?
코드가 아무리 잘 만들어져도, 공개 URL이 없으면 아무도 볼 수 없습니다. Vercel이 그 코드를 인터넷에 공개하고, 이후에도 코드가 바뀔 때마다 자동으로 최신 버전을 배포합니다.

  • Vercel 대시보드에서 자동 배포 완료 상태 확인
  • 생성된 *.vercel.app URL 접속 시연 — 나만의 웹사이트 공개!
  • 도메인 연결 개념 소개 (선택사항 — 가비아, 호스팅케이알 등)
  • 코드 수정 → 자동 재배포 사이클 설명
  • 오늘 배운 전체 흐름 정리: 아이디어 → 프롬프트 → AI 코딩 → GitHub → Vercel → URL
Vercel 대시보드 ↗

💡 참여자 가이드

Vercel 외에도 프로젝트 성격에 따라 최적화된 배포 플랫폼이 있습니다. React/Next.js는 Vercel이 가장 잘 맞고, Python 백엔드라면 Railway나 Render, 정적 사이트는 Netlify나 GitHub Pages도 좋은 선택입니다. 어떤 코드를 만드느냐에 따라 플랫폼을 고르면 됩니다.
